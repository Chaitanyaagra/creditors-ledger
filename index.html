Backup and restore

The backup file holds everything — suppliers, opening balances for every year, all entries and their references. Keep one after each session; the CSV is for reading in Excel, not for restoring.

Cloud sync

Off by default. Fill this in and the ledger syncs across every device that signs in — your laptop, your phone, and your data-entry person's phone. Each entry syncs on its own, so two people can work at the same time without overwriting each other. The app keeps working offline and catches up later.

Read the setup steps in README.txt first. The database rules matter more than anything else here: with Firebase's default test rules, anyone who finds your database URL can read and change your creditor figures.

Not set up

Users

Two PINs. The owner PIN opens everything, including Excel download and this page. The entry PIN opens only the register, and only for purchases, credit notes and debit notes — payments stay with you. Change both from their defaults before handing the file to anyone.

Be clear on what this is: the PIN keeps the wrong person out of the wrong screen, the way a drawer key does. It is not encryption. Anyone who can open this file in a text editor can read the figures, so treat the file itself as the thing to keep private.
